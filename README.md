# lightyou-dist

Public distribution + feedback repository for **LightYou**, an AI-enhanced
local-first reader for macOS, Windows, and Linux.

> This repo holds **binaries and user-facing feedback only**. The application
> source code lives in a separate private repository.

## Download

→ **[Latest release](https://github.com/DoSomeForFun/lightyou-dist/releases/latest)** — `.dmg` / `.msi` / `.exe` / `.AppImage` / `.deb` / `.rpm`, plus the signed `latest.json` used by the in-app auto-updater.

Marketing site with OS auto-detection: **[lightyou.pages.dev](https://lightyou.pages.dev)** _(coming soon)_.

## Feedback

Use the **Send feedback** button inside the app (Settings → Help & feedback)
to open a pre-filled issue. You can also file one directly via the templates
on the [Issues](https://github.com/DoSomeForFun/lightyou-dist/issues/new/choose)
tab:

- **Bug report** — something broken or behaving unexpectedly.
- **Feature request** — ideas and missing capabilities.

Every issue is read. Not every issue is actioned immediately — LightYou is
a small, alpha-stage project.

## What you'll find here

| Path                            | Purpose                                    |
| ------------------------------- | ------------------------------------------ |
| `Releases`                       | Signed binaries for each platform          |
| `latest.json` (release asset)    | Auto-updater manifest                      |
| `.github/ISSUE_TEMPLATE/`        | Bug + feature templates                    |

## What you won't find

- No source code. LightYou is currently closed source.
- No analytics. The app never phones home for telemetry.
